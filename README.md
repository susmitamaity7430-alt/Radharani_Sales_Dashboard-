📊 Radharani Store Sales Dashboard (2026)
📌 Project Overview
This project is based on Radharani Store Sales Data (2026). The main objective is to analyze sales performance and create an interactive dashboard using Microsoft Excel.
The project follows a complete data workflow:
•	Data Cleaning 
•	Data Analysis 
•	Data Insights 
•	Dashboard Creation 
________________________________________
🎯 Objectives
•	Clean and prepare raw sales data 
•	Analyze sales trends and patterns 
•	Generate meaningful business insights 
•	Build an interactive dashboard for decision-making 
________________________________________
🧹 Data Cleaning
In this step, the raw dataset was processed to ensure accuracy and consistency:
•	Removed duplicate records 
•	Handled missing values 
•	Standardized column formats (dates, text, numbers) 
•	Corrected inconsistent data entries 
•	Created proper data structure for analysis 
________________________________________
📈 Data Analysis
Performed analysis using Excel functions and tools:
•	Pivot Tables 
•	Pivot Charts 
•	Lookup Functions (VLOOKUP / XLOOKUP) 
•	Conditional Formatting 
•	Basic statistical analysis 
Key analysis areas:
•	Total Sales 
•	Monthly Sales Trend 
•	Product-wise Performance 
•	Category-wise Sales 
•	Customer Insights 
________________________________________
💡 Data Insights
Some important insights derived from the data:
•	Identified top-performing products 
•	Found highest sales months 
•	Analyzed category contribution to total revenue 
•	Detected low-performing areas for improvement 
•	Observed customer purchasing patterns 
________________________________________
📊 Dashboard Features
An interactive Excel dashboard was created with:
•	Dynamic charts and graphs 
•	Slicers for filtering (Month, Category, Product, etc.) 
•	KPI indicators (Total Sales, Profit, Quantity) 
•	Trend analysis visuals 
________________________________________
🛠️ Tools Used
•	Microsoft Excel 
•	Pivot Tables & Charts 
•	Excel Functions (SUM, COUNT, IF, VLOOKUP/XLOOKUP) 
•	Data Cleaning Techniques
